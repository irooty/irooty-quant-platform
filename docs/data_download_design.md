# 数据下载模块详细设计

## 1. 设计目标

- 实现灵活、可扩展的金融数据下载框架。
- 遵循单一功能原则（Single Responsibility Principle），每次下载任务只处理一种数据类型。
- 支持多数据源（如 baostock、wind），支持多种数据类型（如日线、分钟线、分红等）。
- 下载后自动校验数据完整性（如交易日覆盖）。
- **支持增量更新**：每次下载只补齐本地缺失的数据，无需重复下载已存在数据。

---

## 2. 参数说明

| 参数           | 类型    | 说明                                                                            |
|----------------|---------|-------------------------------------------------------------------------------|
| --config       | str     | 配置文件路径，默认 `market_provider.yaml`                                              |
| --provider     | str     | 金融数据提供方（如 baostock、wind），**必填**                                               |
| --start-date   | str     | 开始日期（YYYY-MM-DD），可选                                                           |
| --end-date     | str     | 结束日期（YYYY-MM-DD），可选                                                           |
| --convert      | bool    | 是否转换为Qlib格式，布尔值                                                               |
| --stock-codes  | str     | 要下载的股票列表，支持逗号分隔字符串（如 sh.600000,sz.000001），或文件路径（如 codes.txt，每行一个或逗号分隔） |
| --interval     | str     | 数据类型，支持1min、5min、15min、30min、1h、1d、1w、1m、1q、1y、dividend，默认1d表示日数据，**决定下载类型**  |

## 3. 单一功能原则下的下载流程

### 3.1 入口主流程（datasets/download.py）

1. **参数解析**：只负责获取用户输入，不做业务逻辑。
2. **配置加载**：只负责读取配置文件，获取 provider 相关信息。
3. **下载器初始化**：只负责实例化对应 provider 的下载器，并传递所有参数。
4. **下载调度**：只负责调用下载器的 `batch_download(interval)`，interval 决定只下载一种类型数据。
5. **可选后处理**：如 `--convert`，只在下载完成后单独处理。

### 3.2 下载器内部（如 BaostockDownloader）

1. **股票池准备**：解析 `stock_codes`，只负责股票池选择。
2. **目标区间准备**：解析 `start_date`、`end_date`，只负责下载区间。
3. **目标集合准备**：根据 `interval`，准备目标集合（如所有交易日、所有分钟、所有分红年份等）。
4. **本地数据读取**：只负责读取本地已有数据。
5. **缺失判断**：只负责判断本地数据与目标集合的差集。
6. **缺失区间下载**：只负责下载缺失区间的数据（不混合其他类型），**实现增量更新**。
7. **数据合并与保存**：只负责合并新旧数据、去重、保存。
8. **状态更新**：只负责记录本次下载的状态。
9. **交易日完整性校验**：只负责校验本地数据是否覆盖所有目标集合。

## 4. 详细流程图

```
参数解析
   ↓
配置加载
   ↓
下载器初始化
   ↓
【单一功能】batch_download(interval)
   ↓
  ├─ 股票池准备
  ├─ 目标区间准备
  ├─ 目标集合准备（由 interval 决定）
  ├─ 本地数据读取
  ├─ 缺失判断
  ├─ 缺失区间下载（只下载 interval 对应类型，支持增量更新）
  ├─ 数据合并与保存
  ├─ 状态更新
  └─ 交易日完整性校验
   ↓
（可选）数据转换
```

- **增量更新**：每次只补齐缺失数据，避免重复下载。

## 6. 可扩展性

- 新增数据类型时，只需实现新的下载方法，并在 interval 映射中注册即可。
- interval 参数与下载方法的映射关系可配置化，便于维护。
- 支持多数据源，支持多种数据类型。

---

## 7. 交易日完整性校验

- 下载完成后，自动校验本地数据是否覆盖所有目标交易日。
- 如有缺失，记录日志、报警，或自动补齐缺失数据。

---

## 8. 设计要点总结

- **单一下载类型**：每次只下载一种类型数据。
- **参数驱动**：通过 interval 参数灵活控制下载内容。
- **高效区间下载**：不分段，直接用缺失区间，减少API调用。
- **下载后校验**：确保本地数据覆盖所有目标交易日。
- **公共流程抽象**：减少重复代码，便于维护。
- **易扩展**：支持新数据类型和新校验逻辑。
- **支持增量更新**：每次只补齐缺失数据，提升效率，节省带宽和存储。
